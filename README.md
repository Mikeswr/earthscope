# EarthScope

**A geospatial intelligence platform for detecting and understanding environmental trends.**

EarthScope analyses long-term environmental time series, estimates trend magnitude using Sen's slope, tests monotonic trends with the Mann-Kendall family of methods, applies false-discovery-rate correction, and reports data-quality and sensitivity diagnostics.

## Current analysis

The initial Ghana analysis uses monthly NASA POWER gridded data for Accra, Kumasi, Tamale, Wa and Takoradi, covering 1981-2025. These are gridded estimates, not direct station observations. Rainfall and surface solar-radiation findings have additional validation limitations documented in the project reports.

## Project status

This repository is being populated from the validated EarthScope project archive. The dashboard and processed datasets will be added in the next project upload.

## Scientific caution

Five sampled locations do not constitute a continuous spatial map. Statistical significance is not proof of causation. Interpret results alongside the methods, quality-control, sensitivity and limitations reports.
